Cisco Switching and Routing 

Overview

This project demonstrates practical networking configuration and troubleshooting using Cisco Packet Tracer. It focuses on Layer 2 switching, VLAN management, link aggregation, spanning tree and Layer 3 inter-VLAN routing.

Technologies and Tools

Cisco Packet Tracer

Cisco IOS CLI

VLANs and Trunking

VTP (VLAN Trunking Protocol)

LACP EtherChannel

Spanning Tree Protocol (STP)

Switched Virtual Interfaces (SVIs)

Inter-VLAN Routing

Practical Tasks

1. Network Topology and IP Addressing

Designed a network using a multilayer switch and access switches.

Connected end devices and assigned IP addresses.

2. VLAN Configuration

Created and configured VLANs 10, 20 and 30.

Assigned access ports to the appropriate VLANs.

Configured trunk links between switches.

3. VTP Configuration

Configured VTP server and client modes.

Configured VLAN information sharing between switches.

4. LACP EtherChannel

Configured EtherChannel using LACP.

Combined multiple physical links into logical port-channels.

Verified EtherChannel operation.

5. Inter-VLAN Routing

Configured SVIs on the multilayer switch.

Enabled IP routing to allow communication between VLANs.

6. Spanning Tree Protocol

Verified STP operation and root bridge election.

Observed root, designated and alternate port states.

Tested the effect of link disconnection.

7. Integrated Testing and Troubleshooting

Verified VLAN and trunk configurations.

Tested same-VLAN communication.

Tested inter-VLAN communication.

Performed network connectivity troubleshooting.
